# hrandsafetycongress.com

Static website for HR + Safety Congress™. Plain HTML, no build step.

- Pages live in folders (`/renew/index.html` → hrandsafetycongress.com/renew).
- Images and the recap video are in `/assets`.
- Signup forms post to the HR + Safety Congress Mailchimp audience.

Hosting: connect this repository to Netlify or Cloudflare Pages with no build command and the publish directory set to `/` (the repository root).
